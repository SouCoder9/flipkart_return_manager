Return Scanner

Dedicated scanner for marking matching return records as received.

Scan a return barcode

⌗
Camera scanner

Camera requires HTTPS and browser permission. If camera scanning is unavailable, type the barcode below.

Accepted matches: Tracking ID, Return ID, Order Item ID, SKU or FSN. Prefer a unique tracking/return ID.

What happens after a match?

1. The return is marked Received.

2. Scan date/time and product details are saved in the log.

3. Received quantity is added to the inventory's Returns Received count.

4. Duplicate scans are rejected to prevent double-counting.

Inventory camera scanner

Point the camera at the product barcode. Camera access requires HTTPS and permission.

Each successful inventory scan adds the selected quantity. Repeated product scans are allowed intentionally.

Inventory scan rules

1. Scan a barcode matching an Inventory SKU or FSN.

2. The app shows the matched product and updated stock count.

3. The quantity is added to Stock Adjustments.

4. Every change is written to the Scan Log.

Upload & Restore Data

Restore data if browser storage/history is cleared, or import an updated workbook.

Upload master file

Choose an Excel workbook (.xlsx/.xls) exported by this app, your original Flipkart return workbook, or a JSON backup made with the Backup button.

Before restoring

• Restore replaces the current browser data with the selected backup/workbook.

• When present, the app imports Returns, Inventory, and Scan Log sheets.

• Older return workbooks without receipt-status columns import as pending.

• Keep a recent Excel or JSON backup somewhere safe.

This is local browser storage, not cloud sync. Data cannot recover itself after browser data is cleared; use this page to upload a backup.
